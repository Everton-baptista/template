# Skill: Análise Quantitativa & Processamento de Dados

Ao analisar conjuntos de dados ou arquivos tabulares:

## 1. Verificação da Integridade
- Calcule a porcentagem de valores nulos ou ausentes.
- Identifique outliers e inconsistências nos tipos de dados.

## 2. Estatística Descritiva & Métrica Chave
- Calcule Média, Mediana, Desvio Padrão, Mínimo e Máximo para colunas numéricas.
- Destaque tendências de crescimento percentual ano-a-ano (YoY) ou mês-a-mês (MoM).

## 3. Apresentação em Tabelas Markdown
- Formate todos os números grandes com separadores de milhar claros.
- Sempre inclua unidades de medida (USD, BRL, %, unidades).
